I build and run the systems behind production platforms, from API and system design through to the pipelines and servers that ship them. I'm a Technical Lead at [Thinkverse Labs](https://think-verse.com?utm_source=github&utm_medium=profile_readme&utm_campaign=github_profile&utm_content=intro) and at [C# Corner](https://www.c-sharpcorner.com?utm_source=github&utm_medium=profile_readme&utm_campaign=github_profile&utm_content=intro), and a C# Corner MVP.

My path is a little unusual: I studied mechanical engineering, worked as an engineer, and taught myself into software. That gave me a practical, systems-first way of thinking: find the bottleneck, fix it, and automate it so it stays fixed.

## ⚡ What I do

- **System & API design:** backend and database architecture for platforms that need to scale.
- **Delivery:** CI/CD, containerisation and cloud infrastructure on Azure, Linux and Docker.
- **Reliability:** performance tuning, reliability work and security hardening.
- **Team:** mentoring engineers, setting engineering standards, and working with product and stakeholders to turn complex requirements into maintainable systems.

## 🔧 Selected work

From nearly four years as a DevOps Engineer at MCN Solutions:

- Built and maintained Jenkins CI/CD pipelines for **100+ production websites and APIs** across Next.js, Node.js and .NET.
- Containerised apps with Docker multi-stage builds and BuildKit cache mounts, **cutting build times by 70%**.
- Set up Nginx reverse proxying and SSH-based deployments to Linux servers.
- Automated server backups to S3-compatible object storage, with retention pruning and restore tooling.
- Managed SQL Server and MySQL for staging and production environments.
